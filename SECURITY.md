# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.x     | ✅                 |

## Reporting a Vulnerability

If you discover a security vulnerability in Nebula, please report it responsibly.

**Do not** open a public issue.

Instead, please use one of the following methods:

- GitHub Private Security Advisories (preferred)
- Or contact the maintainers directly

Please include as much information as possible:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt of your report as soon as possible and keep you informed of the progress.
