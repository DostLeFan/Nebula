# nebula

Node.js bindings for Nebula.

## Installation

```bash
npm install nebula-gb
```

No compilation is required.

Prebuilt binaries are provided for:

- Windows x64
- Linux x64
- Linux ARM64
- macOS x64
- macOS ARM64
